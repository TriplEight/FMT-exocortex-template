# Правила форматирования

> Загружается всегда. Источник: CLAUDE.md § 6 (вынесено для сжатия контекста).

## Язык — русский (БЛОКИРУЮЩЕЕ)

Все ответы, метки, категории, заголовки — на русском. EN только в коде, терминах (DDD, BC, UL), именах файлов.
НЕ: HIGH / MEDIUM / LOW / CRITICAL / DONE. ДА: **критический**, **высокий**, **средний**, **низкий**, **выполнено**.

## Таблицы с РП

- Активные (pending, in_progress): название **жирным**
- Done: зачёркнуть строку без bold (`| ~~#~~ | ~~название~~ | ✅ | ~~done~~ |`). Эмодзи-статусы (✅, 🔄, ↗️, 📦) — **без** `~~`. Тильда `~` внутри `~~` ломает GitHub — заменять `~30 мин` → `30 мин`, `~/IWE` → `IWE`.

## Без HTML/CSS-тегов (БЛОКИРУЮЩЕЕ)

**Запрещены HTML-теги** (`<details>`, `<summary>`, `<div>`, `<span>`, `style=` и др.) во всех документах DS-strategy и вообще везде в IWE — Obsidian ломает отображение, особенно таблицы внутри `<details>`.

**Длинный файл-артефакт >80 строк** (WeekPlan, DayPlan, Strategy, WP-context, спецификации) → структурировать `##`/`###`-заголовками секций, без `---` между секциями. Никакого `<details>/<summary>` — ни как единственного варианта, ни как альтернативы.

**Ответ пилоту, синтез итогов, пост-отчёт** — не оборачивать в HTML-теги (терминал их не сворачивает). Длинный ответ — обычный markdown или файл отчёта; `<details>` в чат — только по явному запросу пилота (усиливает A7/A7.1).

## Ссылки — только wiki-стиль (БЛОКИРУЮЩЕЕ)

Ссылки на другие страницы репозитория — только Obsidian wiki-style `[[Название документа]]` (по имени файла без расширения `.md`, без пути). Markdown-ссылки `[текст](путь/файл.md)` на внутренние документы — запрещены (не резолвятся как заметки в графе Obsidian). Внешние URL (`http://`, `https://`) — обычным markdown-синтаксисом `[текст](url)`, это не затрагивается.
